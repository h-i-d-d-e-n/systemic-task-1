Final Points = 0.4 * (Average of HW ⏐ Median of HW) + 0.6 * Exam
This file contains a student grade calculator, using both the method of average and median:
the file contains:

Class Person:

methods:
Constructor(s).
Assignment-copy operator (the rule of three).
Copy constructor (the rule of three).
Destructor (the rule of three).
Data input method (overloaded cin).
Data output method (overloaded cout).
Calculation method for the final grade (based on median or average - user's choice).

Ability to randomize amount of grades, the actual grades from 1-10, exam, and calculate the final grade.
Additionally, the user can choose if they want to 'R' which is randomize everything, or 'M', which is to manually input all the grades.
Next, the user can manually decided to say they dont know how many grades they will be entering, meaning they can keep adding grades non stop that will later still be calculated using the same formulas.

Finally, the program can read off of a student grades file, where it contains (in my case) 15 different students that each have 5 grades and 1 exam, which will later be read and outputed in the format of Name, Surname, Final Grade (average), Final Grade (median).
